# IncludeCounts

Count the deployments and projects that use this manager. On by default; with "false" the lookup skips the counts and both are returned as 0.

## Example Usage

```typescript
import { IncludeCounts } from "@alienplatform/platform-api/models/operations";

let value: IncludeCounts = "false";
```

## Values

```typescript
"true" | "false"
```
