# Identity

## Overview

Authentication identity

### Available Operations

* [issueEnrollmentCode](#issueenrollmentcode) - Issue the code that `management.enrollmentCode` carries into a Helm install.
* [issueSetupCredential](#issuesetupcredential) - Issue a short-lived key for rerunning an installation, to its own Operator.
* [enrollRuntimeIdentity](#enrollruntimeidentity)
* [exchangeRuntimeIdentity](#exchangeruntimeidentity) - Exchange a verified component proof for one bounded runtime purpose.
* [rotateRuntimeIdentity](#rotateruntimeidentity)

## issueSetupCredential

The caller proves itself with the Operator's live key as the bearer token.
It is not a session: the key is checked against this deployment only, so
every other caller gets the same refusal.
